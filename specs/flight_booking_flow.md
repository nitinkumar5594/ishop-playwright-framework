# iShop Flight Booking Automation Flow

## Target Application
- **URL**: `https://ishop-qa.reward360.in/`
- **Domain**: Travel & Stays -> Flights

## Test Steps
1. **SSO Login**: Log into iShop portal.
2. **Flight Search**: Select One-Way / Round-Trip, origin, destination, dates, and travelers.
3. **Flight Results**: Verify flight listing and fares load.
4. **Flight Selection**: Select flight and review fare summary.
5. **Traveler Details**: Enter passenger details and proceed through checkout.
